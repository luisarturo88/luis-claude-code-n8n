## SECCIÓN 2: ARQUITECTURA HUB & SPOKE

### Concepto General

La red opera bajo modelo **Hub & Spoke** (Centro y Radios). El blog central acumula autoridad de dominio (DA) y la distribuye a los blogs especializados mediante links salientes. Los blogs nicho capturan tráfico long-tail de alta intención y envían señales de autoridad temática de regreso al hub.

```
                        [VETERINARIO LUIS GARCIA]
                         Hub Central de Autoridad
                          DA objetivo: 30+
                                 |
          ┌──────────────────────┼──────────────────────┐
          |                      |                      |
   [ANIMALES EXÓTICOS]   [VETERINARIA CLÍNICA]   [ANIMALES COMUNES]
          |                      |                      |
    ┌─────┴─────┐          ┌─────┴─────┐         ┌─────┴─────┐
    |           |          |           |         |           |
  HURÓN    REPTILES    BULLDOGS    BOV.VET    RAZAS     ALIMENT.
 CHINCH.   GECKOS                           PASTOR    PERROS/GATOS
                                            MASTIN
          |                      |
   [ACUARIOFILIA]         [AVES PSITÁCIDAS]
          |                      |
    ┌─────┴─────┐          ┌─────┴─────┐
    |     |     |          |     |     |
  BETTA GUPPY NANO       LOROS GUAC. PERIQ.
  PLATY CAM.             PATOS
```

### Reglas de Interlinking

**Desde blogs nicho → Hub central:**
- Todo artículo de diagnóstico o urgencia en un blog nicho debe incluir un link a Veterinario Luis Garcia con anchor text contextual (ej: "consulta con un veterinario especializado").
- Artículos de "síntomas de X en hurones" → link a artículo de semiología en hub.
- Mínimo 2 links al hub por artículo largo (>1500 palabras).

**Desde Hub central → Blogs nicho:**
- Artículos del hub sobre animales exóticos deben citar al blog nicho específico.
- Sección "Recursos especializados" al final de cada artículo del hub, con 3–5 links a blogs nicho relevantes.
- El hub no linkea a blogs de temas no relacionados (impuestos, legal).

**Entre blogs nicho del mismo cluster:**
- Cluster acuariofilia: BETTA ↔ GUPPY ↔ PLATY ↔ NANO ↔ CAMARONES. Interlinking cruzado libre.
- Cluster aves: LOROS ↔ GUACAMAYOS ↔ PERIQUITOS. Artículos de comparativas entre especies.
- Cluster salud: HIPERTENSION ↔ TENSIOMETRO ↔ ANTIESTRÉS. Interlinking temático.
- Cluster legal USA: IMPUESTOS ↔ ABOGADOS FAMILIA ↔ ABOG. ACCIDENTES ↔ BIENES RAICES. Interlinking lateral.

**Reglas que NO deben romperse:**
- Los blogs de mascotas NO deben linkear a los blogs legales/impuestos (destruye coherencia temática).
- No hacer link farms ni intercambios de links artificiales entre blogs sin contexto editorial.
- Cada link debe estar justificado por el contenido del párrafo en que aparece.

### Flujo de Autoridad SEO

```
[Backlinks Externos]
        |
        v
[VETERINARIO LUIS GARCIA]  ←── Backlinks de PR, HARO, menciones médicas
        |
        | PageRank + Topical Authority
        v
[Blogs Nicho Veterinarios] ←── Flujo de autoridad desde hub
        |
        | Long-tail traffic + conversiones
        v
[Ingresos: Adsense + Amazon]
```

El hub debe ser el destino de todos los esfuerzos de link building externo (guest posts, menciones en medios, HARO). Su autoridad se distribuye hacia la red de forma natural.

## SECCIÓN 3: ESTRATEGIA PILAR + CLUSTER POR NICHO PRIORITARIO

### Instrucciones de uso

- **Artículo Pilar:** 3000–5000 palabras. Responde a la pregunta principal del nicho. Linkea a todos los artículos cluster.
- **Artículo Cluster:** 800–1500 palabras. Responde a una pregunta específica de long-tail. Linkea al pilar y a 2–3 artículos cluster hermanos.
- **Interlinking bidireccional:** Pilar → Cluster (siempre). Cluster → Pilar (siempre). Cluster → Cluster hermano (cuando es relevante).
